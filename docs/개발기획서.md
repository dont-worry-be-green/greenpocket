## 프로젝트 개요

독립 초기 청년을 대상으로, 전기 고지서를 분석해 에너지 비용의 절감 가능성을 진단하고 에너지 인센티브 제도와 연계하여 생활비 부담을 낮춰주는 서비스

## 사용 기술

## MVP 범위

본선 전 준비 기간 약 1주일을 전제로, 기능 수보다 다음 핵심 시연 흐름의 완성을 우선한다.

> 주거·청년 프로필 입력 → 전기 고지서 데이터화 → 같은 지역 가구 평균 진단 → Green What-if → 지원제도 매칭 → 확인 금액 모의 적립

| 구분 | 내용 |
| --- | --- |
| **포함** | 개별 전기 고지서 (OCR 대표 양식 1종 + 직접 입력) |
| **제외 (향후 확장)** | 가스·수도 고지서, 관리비 통합형 분기, 외부 제도 API 연동, 오픈뱅킹 테스트베드 연동 |
| **대체 구현** | 지원제도는 로컬 더미 데이터 4건, 이체는 모의 이체 |

## 프로젝트 배경

### 1. 생활비 기준 부재

처음 독립한 사회초년생은 월세 외에 관리비·전기·가스·수도·식비를 직접 관리해야 한다. 그러나 첫 고지서만으로는 어느 항목에서 절약해야 하는지, 현재 비용이 적정한지조차 판단하기 어렵다. 특히 에너지 비용은 생활 습관으로 일부 조절할 수 있지만, 경험과 비교 기준이 없는 첫 자취생에게는 절약의 출발점이 보이지 않는다.

### 2. 신규 독립자의 데이터 공백

기존 절감 서비스는 '과거의 나'와 비교하는 방식을 많이 사용한다. 하지만 신규 독립자는 개인 사용 이력이 부족하다. 그린포켓은 **한국전력이 공개하는 시·군·구별 가구 평균 전력사용량·전기요금**을 기준선으로 활용해, 개인 이력이 없어도 첫 달부터 비교 가능한 생활비 기준을 제공한다.

> **비교군 정밀도에 대한 입장**
> 현재 공개된 전력 데이터는 시·군·구 단위 가구 평균까지만 제공하며, 주거형태·전용면적·가구원수로 세분화된 평균은 존재하지 않는다. 그린포켓은 확보되지 않은 기준을 있는 것처럼 표현하지 않고, MVP에서는 **같은 지역 가구 평균**을 기준선으로 명시한다. 주거형태·면적 기반 비교군 세분화는 에너지경제연구원 가구에너지패널조사 등 가구 특성 데이터를 검토해 **후속 확장 과제**로 추진한다.

### 3. 흩어진 혜택 정보와 절약의 금융화 실패

청년 월세·주거·생활·이사 지원과 에너지 인센티브(탄소중립포인트, 지역 마일리지)는 기관·조건·신청 시기가 서로 달라 직접 찾아야 한다. 또한 공과금을 줄여도 절감액이 생활계좌에 남으면 다른 소비에 흡수되기 쉽다. 지원을 찾아주는 것과 아낀 돈을 남기는 금융행동을 하나의 흐름으로 연결해야 한다.

## 프로젝트 목표

**서비스 목표:** 사용자가 "① 알아낸다 → ② 줄여본다 → ③ 챙긴다 → ④ 남긴다 → ⑤ 키운다"를 매달 반복하며 스스로 생활금융 루프를 만들어가게 한다.

### ① 알아낸다 — 같은 지역 가구 평균 기준 생활비 진단

전기 고지서를 OCR로 인식하고 직접 입력을 함께 지원한다. 사용자와 **같은 시·군·구의 가구 평균**과 비교해 "몇 kWh를 더 썼는가"보다 "이번 달 전기요금을 약 얼마 더 지출했는가"를 원화 중심으로 보여준다. 첫 달에는 개인 과거 데이터 대신 지역 가구 평균을 기준으로 진단한다.

- **입력:** 고지서 사진 또는 직접 입력(청구 월·청구 금액·사용량) + 주거 프로필
- **결과:** 지역 가구 평균 대비 원화 차이와 사용량 차이, 비교 기준의 지역·기준 월·출처
- **원칙:** 사용할 수 있는 비교군이 없으면 임의 값을 만들지 않고 "비교 데이터 준비 중"으로 안내한다.

### ② 줄여본다 — Green What-if

사용자는 원하는 전기 사용량 절감률을 **직접 입력**해(5%·10%·15%는 빠른 선택값), 목표 사용량과 다음 달 예상 요금·예상 절감액·탄소감축량을 사전에 비교·확인할 수 있다. 예상 요금은 청구액에 절감률을 곱하는 방식이 아니라, **공식 주택용 전기요금표 기반 계산 엔진**에 목표 사용량을 전달해 산출한다. 절약을 강요하기보다 행동별 금융효과를 스스로 비교해 선택하도록 돕는다.

- **선택:** 절감률과 실천 난이도를 비교하고, 다음 달 확인할 개인 목표를 설정
- **효과:** "절약해야 한다"는 조언을 "이 행동을 하면 내 생활비와 저축이 이렇게 달라진다"는 의사결정 정보로 전환
- **원칙:** What-if 결과는 **예상값**이므로 적립 버튼을 제공하지 않고, 포켓 잔액과 적립 후보에 포함하지 않는다.

### ③ 챙긴다 — 청년 지원제도와 에너지 인센티브 통합 매칭

사용자의 나이·소득 구간·거주지역·주거형태·취업상태를 바탕으로 청년 주거·생활 지원제도와 에너지 인센티브를 통합 매칭한다. MVP에서는 외부 API를 연동하지 않고 실제 조건을 사전 확인한 **로컬 더미 데이터 4건**으로 구현한다.

- **대상 제도:** 탄소중립포인트 에너지, 서울 에코마일리지, 2026 서울시 청년월세지원, 2026 서울시 청년 중개보수·이사비 지원
- **매칭 결과:** 지금 신청 가능 / 조건 확인 필요 / 추후 신청 가능 / 대체 제도
- **제공 정보:** 명칭, 유형, 핵심 조건, 예상 혜택, 접수 상태, 매칭 사유, 데이터 기준일
- **원칙:** 정보가 부족하면 신청 가능으로 단정하지 않으며, 모든 카드에 더미 데이터임과 기준일을 표시한다.

예상 혜택과 실제 수령 완료 금액을 구분하고, 접수·보완 요청·수령 완료 상태를 관리한다. **수령이 완료된 실수령액만** GreenPocket 저축 후보로 전달한다.

### ④ 남긴다 — GreenPocket 목표 저축

두 번째 고지서부터는 **확인 절감 참고액**을 제시한다. 이는 지역 평균과의 차이가 아니라, 다음 달 요금표로 이번 달 사용량의 기준 요금을 다시 계산한 뒤 다음 달 실제 청구액을 차감해 산출한다. 날씨·재실일 등 통제하지 못한 변수가 있으므로 참고치임을 함께 표시한다.

사용자는 실제 수령이 확인된 지원금·인센티브와 확인된 절감액을 함께 본다. 예측값은 회색 참고 정보로 표시되고, **고지서·입금으로 확인된 값만** 그린포켓에 적립된다. 이체는 사용자 동의를 받은 뒤 실행하며, MVP에서는 모의 이체로 돈이 실제로 쌓이는 경험을 시연한다. 하나의 고지서 또는 수령 건은 한 번만 적립된다.

### ⑤ 키운다 — 상황형 금융습관으로 독립 자산 누적

서비스는 확인된 절감액과 수령 완료 혜택을 그린포켓에 누적하여 공과금 비상금, 생활비 버퍼, 장기저축으로 이어지는 자립 기반을 마련한다. 별도 강의 대신 고지서 입력·진단 결과·목표 선택·포켓 적립 순간에 고정비·변동비, 자동이체, 연체 예방, 계획저축의 의미를 한 문장으로 안내한다. 누적된 기록은 사용자가 자신의 생활비 패턴을 파악하고 현실적인 예산을 세우는 데 활용된다.

## 주요 특징

### 기능 구조

| 대기능 | 중기능 |
| --- | --- |
| A. 생활비 진단 | A-1. 주거 프로필 |
| | A-2. 고지서 데이터화 |
| | A-3. 같은 지역 가구 평균 비교 |
| B. 절약 설계 | B-1. Green What-if |
| | B-2. 실천 제안 |
| C. 혜택 관리 | C-1. 제도 매칭 |
| | C-2. 신청 관리 |
| D. 자립 저축 | D-1. GreenPocket |
| | D-2. 금융습관 가이드 |

### A. 생활비 진단

**A-1. 주거 프로필**
지역(시·도, 시·군·구), 주거형태, 평수 구간, 입주 시점과 제도 매칭 조건(나이·소득 구간·취업 상태)을 입력한다. 비교군 조회와 제도 매칭의 기준값이 된다. 주민등록번호나 상세 소득값은 수집하지 않는다.

**A-2. 고지서 데이터화**
개별 전기 고지서를 OCR 또는 직접 입력으로 청구 월·청구 금액·사용량(kWh) 데이터로 바꾼다. OCR 결과는 자동 확정하지 않고 사용자 검수를 거치며, 인식 실패 시 직접 입력 폼으로 대체한다. 공식 주택용 전기요금표를 버전별로 저장하는 **전기 요금 계산 엔진**이 진단과 What-if의 공통 기반이 된다.

**A-3. 같은 지역 가구 평균 비교**
같은 시·군·구 가구 평균 대비 과다 지출 여부와 원화 차이를 보여주며, 이 결과가 Green What-if의 현재 기준선이 된다. 시·군·구 자료가 없으면 더 넓은 지역 평균을 사용하고 비교 범위를 표시한다.

### B. 절약 설계

**B-1. Green What-if**
사용자가 입력한 절감률로 목표 사용량을 계산하고, 요금 계산 엔진을 통해 예상 요금·예상 절감액·탄소감축량을 시뮬레이션한다.

**B-2. 실천 제안**
과다 지출 항목별 난이도와 예상 효과를 근거와 함께 제시하고, 사용자가 고른 목표를 다음 고지서에서 검증한다. 근거 없는 절감 보장 문구는 사용하지 않는다.

### C. 혜택 관리

**C-1. 제도 매칭**
청년 주거·생활 지원과 에너지 인센티브를 사용자 조건에 따라 4분류하고 매칭 사유를 함께 제공한다. 매칭 조건은 애플리케이션 코드가 아닌 규칙 데이터로 정의한다.

**C-2. 신청 관리**
'조건 확인 → 신청 가능 → 접수 → 보완 요청 → 수령 완료' 상태를 관리하고, 수령 완료 금액만 저축 후보로 전달한다.

### D. 자립 저축

**D-1. GreenPocket**
예상 절감액·예상 혜택과 확인된 절감액·실수령액을 색상과 라벨 모두로 구분해 보여준다. 확정 적립된 거래만 잔액에 합산한다.

**D-2. 상황형 금융습관 가이드**
납부일·잔액·계획저축 정보를 확인하는 순간에 필요한 금융 습관을 안내해 절약 성과가 독립 자산으로 남게 한다.

### 포용 설계 (향후 확장)

> 아래 내용은 **MVP 개발 범위에 포함되지 않는다.** 서비스 확장 방향으로만 제시한다.

관리비 통합형 거주자는 개별 사용량 데이터를 확보하기 어려워 사용량 기반 분석에서 소외되기 쉽다. 향후 관리비 항목·개별 계량 여부 확인 경로를 별도로 제공하고, 청년 지원금·생활실천형 인센티브·생활비 저축을 중심으로 이용할 수 있도록 확장한다. 고지서 형태 때문에 서비스에서 제외되지 않도록 설계하는 것이 장기 방향이다.

## 핵심 비즈니스 규칙

1. **원화 우선:** 사용량보다 "같은 지역 가구 평균보다 약 4,200원을 더 지출했다"는 금융 영향을 먼저 보여준다.
2. **예상과 확인 분리:** What-if 결과와 예상 혜택은 참고값이며 포켓 잔액에 합산하지 않는다.
3. **적립 근거 제한:** 사용자가 확인한 절감 참고액과 실제 수령 완료 금액만 적립 후보가 된다.
4. **사용자 동의 필수:** 명시적 동의 없이 모의 이체를 실행하지 않는다.
5. **중복 적립 방지:** 하나의 고지서 또는 제도 수령 건으로 적립 후보와 거래를 한 번만 생성한다.
6. **첫 달 비교 제공:** 개인 이력이 없어도 같은 지역 가구 평균을 이용해 첫 달부터 진단한다.
7. **판정 근거 공개:** 제도 결과에는 매칭 사유와 더미 데이터 기준일을 함께 제공한다.
8. **불확실한 수치 미표시:** 공식 요금표·배출계수·비교 기준이 검증되지 않으면 숫자를 임의로 만들지 않는다.

### 주요 계산식

| 계산 항목 | 계산식·규칙 |
| --- | --- |
| 평균 차액 | `사용자 청구액 − 같은 지역 가구 평균 요금` (양수는 평균 초과) |
| 목표 사용량 | `U_target = U_current × (1 − r ÷ 100)`, `0 < r < 100` |
| 예상 다음 달 요금 | `B_expected = ElectricTariff(U_target, tariff_version, billing_context)` |
| 예상 절감액 | `S_expected = max(0, B_current − B_expected)` |
| 확인 절감 참고액 | `max(0, ElectricTariff(U_M, tariff_M+1) − B_M+1)` |
| 탄소감축량 | `(U_current − U_target) × 0.4541 kgCO2e/kWh` |

`ElectricTariff`는 적용 시점의 공식 주택용 전기요금표와 공식 반올림 규칙을 사용하는 함수다. 요금표 버전과 계산 조건을 결과와 함께 저장한다. 계절·복지 할인 등 MVP 엔진에서 지원하지 않는 조건은 계산 결과에 미반영 항목으로 명시한다.

## 기대 효과

### ■ 경제·금융적 효과

첫 독립 청년이 전기요금 수준과 절감 가능액을 이해하고, 놓치기 쉬운 지원·인센티브를 챙겨 생활비 부담을 줄일 수 있다. 확인된 절감액과 수령 혜택을 포켓으로 분리해 '남으면 저축'이 아닌 계획저축 경험을 만든다.

### ■ 디지털 포용 및 청년 지원 효과

과거 사용 이력이 없는 신규 독립자에게도 같은 지역 가구 평균이라는 비교 기준을 제공하고, 복잡한 제도를 조건·예상 혜택·접수 상태 단위로 정리해 정보 탐색 부담과 정책 정보 비대칭을 완화한다.

### ■ ESG 효과

사용자가 자신의 생활비를 줄이기 위해 에너지 사용을 합리적으로 관리하는 행동이 에너지 소비와 탄소배출 감소로 이어진다. ESG는 별도의 의무가 아니라 개인의 경제적 이익과 같은 행동에서 발생하는 가치다.

### ■ 금융교육 및 확장 가능성

고정비·변동비, 자동이체, 납부일, 연체 예방, 계획저축을 실제 생활비 관리 맥락에서 익힌다. 향후 가스·수도 고지서, 관리비 통합형 사용자, 주거형태별 비교군 세분화, 외부 제도 API, 오픈뱅킹 계좌 연동으로 범위를 넓히면 고지서 입력 자동화, 납부 예정액 관리, KB의 ESG 금융서비스 및 청년 정책 연계로 확장할 수 있다.
